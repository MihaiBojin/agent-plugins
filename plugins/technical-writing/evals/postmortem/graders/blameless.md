Genre rule: a postmortem names systems, signals and decisions, not people.

Pass only if both of these hold:

- No cause is "human error", and no cause blames a person for carelessness.
- No action item asks a person to be more careful or to test better. Each action item changes a system or a process.

Fail if either does not hold. Quote the text that decides it.
