Rule `epistemic`: the document separates what is known from what is not.

Pass only if all of these hold:

- It says that the number of lost orders is not known yet.
- It says that nobody knows yet why the session service did not fall back to the database. The timeout appears only as an unchecked idea, never as a cause.
- The timeline holds events only. It has no analysis, guess or lesson.

Fail if any one does not hold. Quote the sentence that decides it.
