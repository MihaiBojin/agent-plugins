# Decision request

Reader: the person who must choose.

## Shape

A request has five parts, in under 200 words:

1. The recommendation.
2. The reason.
3. The trade-off.
4. The deadline.
5. The cost of not deciding.

## Rules

- Letter the options in recommendation order: a, b, c.
- A choice written as a sentence is still a choice. "We could drop the flag or
  keep it behind a config key" is two options, so letter them.

Sources: the decision format and the thread protocol in the dialogue plugin.
