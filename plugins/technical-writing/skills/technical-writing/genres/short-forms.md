# Short forms

Each form below needs one line of guidance:

- Security advisory: affected versions, severity, impact, fixed versions,
  workaround, credit. Practice.
- API reference entry: one sentence on its purpose, a parameter table, the
  return value, errors and an example. Practice; TW1 Lists and tables.
- CLI help: a usage line, one sentence on its purpose, a table of flags, and
  examples. Practice.
- Log message: a stable event identifier, the identifiers involved as key and
  value pairs, and text that stays the same when the wording elsewhere
  changes. Google Writing Helpful Error Messages, back-end guidelines.
- FAQ: questions in the reader's words, each answer first. Practice.
- Meeting notes: decisions, action items with owners, and open questions,
  never a transcript. Practice.
- Interview question: one question at a time, with lettered options.
  Practice.
- Alt text: the purpose of the image in its surrounding text, as a phrase or
  one or two sentences, with the first word capitalized, a final period, and
  no "Image of". A decorative image takes `alt=""`. For a graph or diagram,
  the alt text gives the takeaway, and the body or a linked data table gives
  the full description. Tech Writing for Accessibility, Write helpful alt
  text.
