Genre shape: each alternative carries the reason it lost.

Pass only if the document lists these three alternatives, each with its reason:

- A larger VM: twice the CPU cut the run only to 4 hours 50 minutes, because the job runs on one thread.
- A multi-threaded cron job in place: it still restarts from zero after a crash.
- A billing SaaS: the quote was $180,000 per year, and it does not support the custom tax rules.

Fail if an alternative or its reason is missing. Name the one that decides it.
