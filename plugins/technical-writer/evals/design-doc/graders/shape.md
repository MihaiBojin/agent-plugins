Genre shape: a design doc has nine sections.

Pass only if the document has a heading for each of these, in this order, with text under every heading. The heading text may differ when the meaning is the same:

1. Summary
2. Audience and prerequisites
3. Context
4. Goals and non-goals
5. Proposal
6. Alternatives considered
7. Risks, trade-offs and costs
8. Rollout, migration and testing
9. Open questions

Fail if a section is missing, merged into another, empty, or out of order. Name the section that decides it.
